一、部署手册

1. 系统要求

项目要求
操作系统Windows 10 / Windows 11 / Windows Server 2016 及以上
内存≥ 2 GB（建议 4 GB）
磁盘≥ 500 MB（数据库与日志随使用增长）
网络能访问域控的 LDAP 端口（默认 389 / SSL 636）
运行账号具备域管理员权限（Domain Admins）的账号，用于读写域对象

注：本系统是 Web 服务，需长期运行，建议部署在服务器或专用机器上。

2. 安装步骤

方式 A：安装包（推荐）

  1. 双击 AD域控管理系统_安装程序_v1.0.3.exe
  2. 按向导完成安装（默认注册为 Windows 服务，开机自启）
  3. 安装完成后，浏览器访问 http://127.0.0.1:8000

方式 B：便携单文件

  1. 将 AD域控管理系统.exe 放到固定目录（勿放临时目录）
  2. 双击运行，首次启动较慢（约 10~20 秒，自解压）
  3. 首次运行会在 exe 同级自动创建 database\ 与 logs\
注意：程序监听 127.0.0.1:8000。如需局域网访问，启动参数加 --host 0.0.0.0，并确保防火墙放通 8000 端口。

3. 初始配置

  1. 访问登录页，使用默认账号 admin / powershell@2025 登录
  2. 登录后立即到「个人中心」修改默认密码
  3. 建议到「系统设置」检查数据目录、日志保留天数等参数
安全提示：默认密码仅用于首次登录，请务必修改，避免域管理后台被未授权访问。

4. 添加域控

进入「多域管理」→「新增域」，填写以下信息：

字段说明
名称自定义显示名，如「总部域控」
域名AD 域名，如 corp.example.com
域控主机域控 IP 或主机名，如 192.168.1.10
管理员账号 / 密码域管理员账号（写操作、改密码需加密通道）
LDAP 端口 / SSL明文 389；如需改密码，建议开启 SSL 使用 636

保存后点「测试」验证连通性。看到「连接成功」即接入完成。

5. 首次同步

  1. 添加域后，系统会提示「建议立即执行一次全量同步」
  2. 在域卡片点「全量」按钮，将 AD 中的用户 / OU / 组 / 计算机同步到本地缓存
  3. 之后系统默认每 15 分钟自动增量同步，无需人工干预

同步完成后，即可在「用户管理」「部门 OU」等页面看到域内数据。

6. 部署排错

现象排查
测试连接失败「网络不可达」检查域控是否在线、防火墙是否放通 LDAP 端口
「认证失败 / 密码错误」检查管理员账号密码、账号是否被锁定
「端口被拒绝」域控对应服务未启动，或端口已修改
无法修改密码改密码需加密通道，请开启 SSL（636）
端口 8000 被占用结束占用进程，或用 --port 换端口

二、管理员手册

1. 登录与账号

系统内置超级管理员账号，登录后可管理所有域。账号信息可在「个人中心」修改密码。

所有写操作均直连 AD 实时生效，并写入操作日志（记录操作人 / 时间 / IP / 结果），做到可审计。

2. 用户管理

  • 新增用户：填登录名、显示名、初始密码、所属 OU；初始密码需符合复杂度，默认首次登录改密。
  • 编辑：改显示名（会触发 DN 变更）、部门、职位、邮箱等。
  • 禁用 / 启用：禁用后用户无法登录域。
  • 重置密码：高危操作，需二次确认。
  • 解锁：解除账号锁定。
  • 移动 OU：跨 OU 迁移用户。
  • 离职处理：一键「移除所有组 + 禁用 + 可选移入离职 OU」。
  • 删除：删除后进入回收站，30 天内可还原。
  • 右键菜单：对任意行右键可快速执行上述操作。

3. OU 管理

  • 树形展示部门组织单元，支持新建子 OU、重命名、编辑描述、递归删除。
  • 批量迁移：把某个 OU 子树下的用户批量移动到目标 OU。
  • 重命名 OU 会级联更新其下所有子对象的 DN 缓存。

4. 用户组 / 计算机

用户组：新建 / 删除组，批量增删成员；内置受保护组（如 Domain Admins）禁止删除。

计算机：列表查看、编辑描述 / 备注、禁用（阻止设备登录域）、删除。

5. 多域 / 林间信任

多域管理：接入多个域控，独立同步、独立管理，域之间故障隔离。

林间信任：在两个林之间建立 / 撤销信任关系。系统会自动配置 DNS 条件转发器、执行 netdom、双向校验。

6. 日志 / 回收站 / 告警

日志审计：所有变更留痕，支持按域 / 模块 / 操作人 / 时间筛选与导出；默认保留 90 天自动归档，可手动「全部清理」。

回收站：删除的用户 / OU / 组 / 计算机先进入回收站，30 天内可还原，到期自动永久删除。

告警中心：集中展示锁定账号、密码即将到期 / 已过期、离线域、长期离线设备等异常。

7. 批量操作 / 导入导出

批量操作：勾选多个用户，批量禁用 / 启用 / 解锁 / 移动 / 加组 / 重置密码 / 改属性 / 删除。

导入：下载模板 → 填写 → 上传校验 → 执行导入；校验失败可导出错误明细。

导出：按筛选条件（域 / 关键词 / 状态 / 部门 / 职位 / 注册时间）选择性导出 Excel。

三、常见问题 FAQ

Q1：测试连接一直失败，提示「网络不可达」怎么办？

先确认域控开机、服务正常；再检查本机到域控的防火墙是否放通 LDAP 端口（389 或 636）。可用 telnet 域控IP 389 快速验证端口连通性。

Q2：为什么域状态变成「离线只读」？

通常是增量同步失败（网络抖动 / 凭据变更）。系统每 2 分钟自动重试探测，恢复后自动转「在线」。若持续离线，请检查域控可达性与管理员凭据。

Q3：修改密码报错「需加密通道」？

AD 修改 unicodePwd 要求加密连接。请在域配置中开启 SSL（端口 636），或确保域控支持 STARTTLS。

Q4：导入用户时提示校验失败？

校验阶段只做格式检查（登录名格式、必填、密码强度、重复），不会写 AD。请按错误明细修正后重新上传，或用「导出错误明细」离线修正。

Q5：授权激活失败，提示「尚未配置许可公钥」？

公钥已内置，正常无需配置。若提示验签失败，说明许可文件与当前客户端密钥不匹配——请用许可服务器重新签发，并确保许可文件未被改动。

Q6：创建林间信任失败，提示「对方域无法联系」？

多为 DNS 解析问题：两侧域控需能互相解析对方域名（系统会自动配置 DNS 条件转发器）。也请确认对方域控放通 389/445/135 及 RPC 动态端口。

Q7：数据会不会丢失？

写操作直连 AD，本地 SQLite 仅作读缓存，删除的对象先进回收站（30 天可还原），日志默认归档保留。

四、试用引导

1. 试用说明

  • 首次运行自动进入 30 天试用期，期间全部功能开放。
  • 试用期按真实流逝时间计算，修改系统时间无法延长。
  • 试用结束后系统进入只读，需导入许可文件激活恢复写操作。

2. 激活流程

  1. 在「授权信息」页查看机器指纹，如需绑定机器可复制给供应商。
  2. 供应商在许可服务器签发许可，交付 .lic 文件（或许可内容文本）。
  3. 回到「授权信息」页，上传 .lic 文件或粘贴许可内容，点击「导入并激活」。
  4. 激活成功后显示客户名、版本、有效期；有期限许可会显示剩余天数和到期日期。

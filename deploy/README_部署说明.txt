AD 域控管理系统 · 部署说明
================================================================

一、运行环境
  1. Windows 10 / Windows 11 / Windows Server 2016 及以上（64 位）
  2. 需要能访问各 AD 域控的以下端口：
       389  LDAP（必需）
       636  LDAPS（修改/重置 AD 用户密码必需，或域控允许 STARTTLS）
       5985 / 5986  WinRM（仅"一键创建林间信任"需要）
       53 / 88 / 135 / 445 / 49152-65535  （建立林信任时的 RPC 与 Kerberos）
  3. 浏览器：Edge / Chrome / Firefox 近两年版本

二、目录说明
  <安装目录>                       程序文件（exe、_internal、模板、静态资源）
  %ProgramData%\AD域控管理系统\database\ad_cache.db    SQLite 缓存数据库
  %ProgramData%\AD域控管理系统\logs\app.log            运行日志
  %ProgramData%\AD域控管理系统\logs\archive\           过期操作日志归档（CSV.gz）
  database\.secret.key             凭据加密密钥（勿删除、勿外传；删除后需重新录入域密码）

三、首次启动
  1. 双击桌面快捷方式（或 run_server.bat）
  2. 浏览器打开 http://127.0.0.1:8000/
  3. 默认账号 admin / powershell@2025  ——  登录后立刻在"个人信息"中修改
  4. 进入"多域管理"→"新增域"：填入贵单位的 AD 域控信息（域名 / 域控 IP / 管理员账号密码），
     保存后点"测试连通性"
  5. 状态变为"在线"后，点"全量"执行首次同步，缓存就绪后各页面即可使用

四、日常运维要点
  · 写操作（增删改、重置密码、移动 OU、建信任）直连 AD，成功后立即回写缓存单行
  · 列表 / 搜索 / 分页 / 筛选 / 仪表盘 / 导出 全部读 SQLite 缓存，不压域控
  · 增量同步：每域独立任务，默认 15 分钟（基于 uSNChanged）
  · 全量同步：每日 02:00，同时清理已删除对象
  · 林信任状态：每 30 分钟刷新
  · 日志维护：每日 03:10 归档 90 天前日志并 VACUUM
  · 域离线时该域自动只读，其他域不受影响；恢复后可在多域管理页手动同步

五、安全建议
  1. 修改默认管理员密码，并按人员创建独立运维账号（区分超级管理员 / 普通运维）
  2. 生产环境通过环境变量注入密钥：
         set ADM_SECRET_KEY=<32 位以上随机字符串>
     否则重启后登录会话失效（不影响数据）
  3. 域管理员账号建议使用专用服务账号，仅授予必要 OU 的委派权限，而非 Domain Admins
  4. 仅在内网使用；如需对外访问，请在前面加 Nginx/IIS 反向代理并启用 HTTPS
  5. 定期备份 database\ad_cache.db（可直接复制，WAL 模式下建议先停止服务）
  6. 系统账号密码连续 5 次失败锁定 5 分钟；会话 120 分钟无操作自动退出

六、Windows Defender / 杀毒软件误报处理
  PyInstaller 打包的 Python 程序常被启发式引擎误判（尤其 onefile 版本），属行业普遍现象：
  1. 优先使用"单目录版"，误报率显著低于单文件版
  2. 将安装目录加入 Defender 排除项：
        设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护
        → 管理设置 → 排除项 → 添加文件夹
  3. PowerShell 方式（管理员）：
        Add-MpPreference -ExclusionPath "C:\Program Files\AD域控管理系统"
        Add-MpPreference -ExclusionPath "$env:ProgramData\AD域控管理系统"
  4. 正式发布建议对 exe 做代码签名（EV 证书可显著降低拦截率）
  5. 本程序不含任何网络下载、注册表写入以外的敏感行为；如仍被拦截，
     可将日志中报告的 SHA256 与文件名提交厂商申诉

七、常见问题
  Q1 登录提示"域离线"？
     检查：能否 ping 通域控、389 端口是否放通、管理员密码是否正确、
     账号是否被锁定（连续失败）。可在"多域管理 → 测试"查看具体失败原因。

  Q2 重置密码失败："需要加密通道"？
     需开启域控 636 端口（LDAPS），或允许 STARTTLS。系统会优先尝试 LDAPS，
     失败后自动回退 STARTTLS；两者都不可用时无法修改密码。

  Q3 创建林间信任失败：预检不通过？
     确认双域控 5985（或 5986）可达、已 Enable-PSRemoting、账号具备域管理权限；
     对方域名需可解析（可先在 DNS 中加条件转发）。

  Q4 缓存数据与 AD 不一致？
     在多域管理页点"增量同步"；若怀疑漏数据，执行一次"全量"即可重建。

  Q5 端口 8000 被占用？
     启动时加参数指定其他端口：AD域控管理系统.exe --prod --port 8080
